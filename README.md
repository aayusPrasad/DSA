# DSA Practice Repository

A curated collection of Data Structures and Algorithms (DSA) practice material organized by topic. This repository is designed as a personal revision hub for problems completed across platforms such as LeetCode and GeeksforGeeks.

## Overview

The goal of this repository is to make DSA revision structured, searchable, and repeatable. Each topic folder contains problem references or screenshots captured during practice, making it easier to revisit concepts, identify patterns, and track progress over time.

## Topics Covered

| Topic | Focus Areas |
| --- | --- |
| Backtracking | Recursion, decision trees, exhaustive search, constraint-based exploration |
| Binary Tree | Tree traversal, recursion, height/depth problems, tree properties |
| Bit Manipulation | Bitwise operators, masks, XOR patterns, binary representation tricks |
| Graph | BFS, DFS, connected components, graph traversal, shortest-path style thinking |
| Math for DSA | Number theory, arithmetic patterns, modular operations, math-based problem solving |
| Matrix | Grid traversal, simulation, search, row/column transformations |
| Queue | FIFO processing, breadth-first workflows, scheduling-style problems |
| Sorting | Comparison logic, custom ordering, array rearrangement, sorting-based optimization |
| Stack | Monotonic stacks, expression handling, next greater/smaller patterns |
| String | Pattern matching, frequency counting, parsing, substring and subsequence problems |
| Two Pointer | Window movement, pair finding, sorted-array techniques, in-place traversal |

## How to Use This Repository

1. Pick a topic folder based on the concept you want to revise.
2. Review the saved problem references and screenshots.
3. Re-solve the problem without looking at the original approach.
4. Compare your solution with the known pattern or platform discussion.
5. Record key observations, edge cases, and time/space complexity notes as the repository grows.

## Suggested Revision Workflow

For each problem, use the following checklist:

- [ ] Understand the problem statement and constraints.
- [ ] Identify the underlying pattern or data structure.
- [ ] Write a brute-force solution first, if useful.
- [ ] Optimize using the appropriate DSA technique.
- [ ] Analyze time and space complexity.
- [ ] Revisit after a few days to confirm long-term retention.
